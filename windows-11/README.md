
# Windows 11 Hardening and Security Monitoring Lab

## Project Overview

This project demonstrates the hardening of a Windows 11 virtual machine using industry-standard security practices inspired by CIS Benchmarks and Microsoft security recommendations. The objective was to reduce attack surface, improve endpoint visibility, and validate security controls through centralized log collection and monitoring in Splunk.

The lab environment was built using VirtualBox and integrated with a SIEM platform to simulate real-world security operations center (SOC) monitoring.

---

## Objectives

* Harden a Windows 11 endpoint against common attack techniques
* Enable detailed security auditing and logging
* Deploy Sysmon for enhanced endpoint visibility
* Forward Windows and Sysmon logs to Splunk
* Validate security events through monitoring and analysis
* Gain hands-on experience with defensive security controls

## Windows Hardening Activities

### Endpoint Protection

* Verified Microsoft Defender Antivirus was enabled
* Verified real-time protection was active
* Enabled Tamper Protection
* Confirmed Windows Defender Firewall was enabled for:

  * Domain Profile
  * Private Profile
  * Public Profile

### Account Security

* Disabled the Guest account
* Renamed the default Administrator account
* Configured password complexity requirements
* Set minimum password length requirements
* Configured password history enforcement
* Implemented account lockout thresholds

### Attack Surface Reduction

* Disabled SMBv1 protocol
* Disabled unnecessary services
* Disabled AutoPlay functionality
* Reduced exposure to legacy and insecure protocols

### Audit Policy Configuration

Enabled advanced auditing for:

* Successful logons
* Failed logons
* Account lockouts
* Special logons
* Process creation events

### Process Monitoring

Enabled command-line auditing for process creation events to improve visibility into executed commands and attacker activity.

## Sysmon Deployment

Sysmon was installed to provide detailed endpoint telemetry.

### Key Benefits

* Process creation monitoring
* Network connection monitoring
* Registry change visibility
* DNS query logging
* File creation monitoring
* Parent-child process relationships

### Validation

Verified Sysmon events within:

Applications and Services Logs → Microsoft → Windows → Sysmon → Operational

## Lessons Learned

This project demonstrated that endpoint hardening and security monitoring work together to improve an organization's defensive posture. While hardening reduces attack opportunities, logging and monitoring provide visibility necessary for detection and incident response.

The deployment of Sysmon and Splunk significantly improved endpoint visibility and provided practical experience analyzing security-relevant events generated by Windows systems.
